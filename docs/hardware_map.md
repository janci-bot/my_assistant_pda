# PicoCalc Hardware Map

## CPU

RP2350 @ 230 MHz

## LCD

Controller: ST7789

Resolution: 320x320

Frame buffer: 320x480

SPI1

GPIO10 SCK
GPIO11 MOSI
GPIO12 MISO
GPIO13 CS
GPIO14 DC
GPIO15 RST

## Southbridge

I2C1

GPIO6 SDA
GPIO7 SCL

Address: 0x1F

## Registers

0x04 KEY
0x05 LCD_BACKLIGHT
0x08 RESET
0x09 KEY_FIFO
0x0A KEYBOARD_BACKLIGHT
0x0B BATTERY
0x0E POWER_OFF

## Confirmed keys

BACK = 8

SHIFT = 162

ESC = 177
